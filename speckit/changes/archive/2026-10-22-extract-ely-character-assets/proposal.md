# Proposal

## Why

当前 Ely 的 SVG 图层、颜色、顺序、包围框、转动中心和动作绑定直接定义在 `src/pet/rig.rs`，素材维护与渲染实现耦合。先将现有立绘拆成独立资源，为后续可配置角色建立边界，而不在本次引入通用角色系统。

## What Changes

- 将现有 Ely 的全部图层素材与静态角色描述迁移至 `assets/pet/ely/`，保留图层顺序、数值和绘制语义。
- 用 JSON 描述图层及其既有动作绑定，SVG 文件保存对应图层；资源随可执行文件内嵌，无运行时磁盘依赖。
- Rust 保留资源解析、校验、动画计算、绘制和交互；删除原有内联素材与重复描述。
- 保持外观、表情、动画时序、视线跟随、点击、拖动、尺寸及跨平台定位不变。
- 增加迁移一致性、资源校验和渲染回归验证。
- 不增加角色选择、外部导入、热重载、设置字段、第二角色、动作编辑器或 Live2D 支持；不改变应用图标。

## Impact

- Affected specs: `ely-character-assets`（新增，描述内置角色资源与行为保持要求）。
- Affected code: `src/pet/rig.rs`、新增资源描述/加载模块、`src/pet.rs` 的资源初始化接入、相关测试，以及新增 `assets/pet/ely/`。
- `src/pet/look.rs`、`src/pet/gaze.rs`、`src/pet/view.rs` 与平台定位模块的行为保持不变，必要的类型接入不改变其算法。
- 复用现有 serde/serde_json；资源内嵌保持单文件程序的分发方式及原有配置兼容性。
